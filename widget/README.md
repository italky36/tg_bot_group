# SupportHub Chat Widget

Легкий и простой в интеграции виджет чата для поддержки клиентов на вашем сайте.

## Возможности

- **Автоматическая идентификация посетителей** - уникальный ID сохраняется в localStorage
- **История переписки** - посетитель видит предыдущие сообщения при повторном открытии
- **Индикаторы доставки и прочтения** - ✓ (отправлено), ✓✓ (прочитано)
- **Уведомления о новых сообщениях** - пульсирующая иконка и badge с количеством непрочитанных
- **Адаптивный дизайн** - работает на десктопе и мобильных устройствах
- **Автоматическое переподключение** - при разрыве соединения виджет пытается переподключиться
- **Легкий вес** - минимальный размер для быстрой загрузки
- **Интеграция с Telegram** - все сообщения попадают в Telegram-группу операторам

## Установка

### Шаг 1: Разместите файлы виджета

Разместите файлы `chat-widget.js` на вашем сервере или используйте раздачу через админ-панель.

### Шаг 2: Добавьте код на сайт

Добавьте следующий код перед закрывающим тегом `</body>`:

```html
<script>
    // Настройки виджета
    window.SUPPORTHUB_WS_URL = 'ws://your-domain.com/ws/widget';
    window.SUPPORTHUB_COLOR = '#007bff';
    window.SUPPORTHUB_POSITION = 'bottom-right';
</script>
<script src="http://your-domain.com/widget/chat-widget.js"></script>
```

### Шаг 3: Настройте параметры

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `SUPPORTHUB_WS_URL` | URL WebSocket сервера (обязательный) | - |
| `SUPPORTHUB_COLOR` | Основной цвет виджета | `#007bff` |
| `SUPPORTHUB_POSITION` | Позиция: `bottom-right` или `bottom-left` | `bottom-right` |
| `SUPPORTHUB_GREETING` | Приветственное сообщение | `Здравствуйте! Чем можем помочь?` |

## Интеграция с Tilda

1. Откройте настройки сайта в Tilda
2. Перейдите в раздел **"Настройки сайта"** → **"Еще"**
3. В поле **"HTML-код для вставки внутри head"** добавьте:
   ```html
   <script>
       window.SUPPORTHUB_WS_URL = 'ws://your-domain.com/ws/widget';
       window.SUPPORTHUB_COLOR = '#007bff';
   </script>
   ```
4. В поле **"HTML-код для вставки перед /body"** добавьте:
   ```html
   <script src="http://your-domain.com/widget/chat-widget.js"></script>
   ```
5. Сохраните изменения

## Настройка сервера

### Запуск админ-панели с WebSocket

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите админ-панель (включает WebSocket сервер)
python run_admin.py
```

Админ-панель будет доступна по адресу `http://localhost:8000`, а WebSocket по `ws://localhost:8000/ws/widget`.

### Настройка для production

Для production-окружения рекомендуется:

1. **Использовать HTTPS/WSS**:
   ```javascript
   window.SUPPORTHUB_WS_URL = 'wss://your-domain.com/ws/widget';
   ```

2. **Настроить nginx как reverse proxy**:
   ```nginx
   location /ws/widget {
       proxy_pass http://localhost:8000;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection "upgrade";
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_read_timeout 86400;
   }
   ```

3. **Использовать systemd для автозапуска**:
   ```ini
   [Unit]
   Description=SupportHub Admin Panel
   After=network.target

   [Service]
   Type=simple
   User=www-data
   WorkingDirectory=/path/to/tg_bot_group
   Environment="PATH=/path/to/venv/bin"
   ExecStart=/path/to/venv/bin/python run_admin.py
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```

## Настройка Telegram-бота

1. Создайте Telegram-группу с включенными Topics
2. Добавьте бота в группу как администратора с правом "Manage Topics"
3. Настройте переменные окружения в `.env`:
   ```
   BOT_TOKEN=your_bot_token
   SUPPORT_GROUP_ID=-1001234567890
   ```
4. Запустите бота:
   ```bash
   python run.py
   ```

## Команды для операторов в Telegram

### `/rename [новое название]`
Переименовать тему диалога. Например:
```
/rename Клиент: example@gmail.com
```

### `/close`
Закрыть диалог. Посетитель получит уведомление о закрытии.

### `/info`
Показать информацию о посетителе и диалоге (страница, email, время создания).

### `/open`
Повторно открыть закрытый диалог.

## Работа с посетителями

### Идентификация
При первом открытии виджета генерируется уникальный `visitor_id`, который сохраняется в `localStorage`. Это позволяет сохранять историю диалога при повторных посещениях.

### Дополнительная информация
Можно передать дополнительные данные о посетителе (email, имя) через виджет, если у вас есть авторизация на сайте.

### Метаданные
Автоматически сохраняются:
- URL страницы, с которой написал посетитель
- User-Agent браузера
- Время обращения

## Структура сообщений

### От посетителя к оператору
Сообщения отображаются в Telegram-группе в отдельной теме с форматом:
```
Новая заявка #0001 (WEB)
Тема: #WEB_A1B2C3D4
Посетитель: Visitor A1B2C3D4
Email: user@example.com (если указан)
Страница: https://example.com/contact
Дата: 04.12.2025 15:30
──────────────────────────────
[Текст сообщения от посетителя]
```

### От оператора к посетителю
Операторы просто отвечают в теме диалога в Telegram, и их сообщения автоматически попадают в виджет на сайте.

## Устранение неполадок

### Виджет не подключается
- Проверьте правильность URL WebSocket
- Убедитесь, что админ-панель запущена
- Проверьте консоль браузера на наличие ошибок

### Сообщения не отправляются в Telegram
- Убедитесь, что бот запущен
- Проверьте права бота в группе (должен быть администратором с правом "Manage Topics")
- Проверьте правильность `SUPPORT_GROUP_ID` в `.env`

### История не сохраняется
- Проверьте, что `localStorage` доступен в браузере
- Убедитесь, что посетитель использует один и тот же браузер

## Производительность

- Асинхронная загрузка скрипта
- Минимальный размер (< 100 КБ в gzipped формате)
- Эффективное использование WebSocket
- Автоматическое переподключение с exponential backoff

- Firefox (последние версии)
- Safari (последние версии)
- Мобильные браузеры (iOS Safari, Chrome Mobile)
