Пример интеграции SupportHub Chat Widget

Это демонстрационная страница с интегрированным виджетом чата поддержки.

Инструкция по установке

1. Базовая установка

Добавьте следующий код перед закрывающим тегом </body>:

<script>
  // Настройки виджета
  window.SUPPORTHUB_WS_URL = 'ws://your-server.com/ws/widget';
  window.SUPPORTHUB_COLOR = '#007bff';
  window.SUPPORTHUB_POSITION = 'bottom-right';
</script>
<script src="https://your-server.com/widget/chat-widget.js"></script>

2. Параметры настройки

  • SUPPORTHUB_WS_URL - URL WebSocket сервера (обязательный)
  • SUPPORTHUB_COLOR - Основной цвет виджета (по умолчанию: #007bff)
  • SUPPORTHUB_POSITION - Позиция виджета: 'bottom-right' или 'bottom-left' (по умолчанию: bottom-right)
  • SUPPORTHUB_GREETING - Приветственное сообщение (по умолчанию: "Здравствуйте! Чем можем помочь?")

3. Для Tilda

В настройках сайта:

  1. Перейдите в "Настройки сайта" → "Еще" → "HTML-код для вставки внутри head"
  2. Вставьте код настроек (window.SUPPORTHUB_*)
  3. Перейдите в "HTML-код для вставки перед /body"
  4. Вставьте код загрузки скрипта

Возможности

  • Автоматическое сохранение истории чата
  • Уникальная идентификация посетителя
  • Индикаторы доставки и прочтения
  • Уведомления о новых сообщениях
  • Адаптивный дизайн
  • Автоматическое переподключение при разрыве соединения
